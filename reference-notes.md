# Reference-site translation notes

The supplied DW Laser reference used a simple sales path: a compact branded header, a large hero with two primary actions, trust/benefit blocks, a visual showcase, local contact details, and a quote form. The Franz Wieler site translates this flow rather than copying its business assets or wording.

| Reference convention | Franz Wieler translation |
| --- | --- |
| Shop catalog button | WhatsApp Catalog button (`wa.me/c/59163544951`) |
| Custom request | Direct WhatsApp quote request with a prefilled Spanish message |
| Product showcase | Roofing, tinglado, and steel-work gallery |
| Studio/service information | Pailón, Santa Cruz coverage information |
| Custom project form | Construction quote form that opens WhatsApp with entered details |

All original DW Laser branding, CustomThings URLs, product language, contacts, and reviews are intentionally excluded.
